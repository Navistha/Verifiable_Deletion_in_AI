# ml/apps-audit/scanners

**Who works here:** ml1 (three real apps, canaries, vector and index scanning, early ML items in weeks 1-12)

**What goes here:** Python scanners for Chroma and Weaviate index files, nearest-neighbour probes (embed canary, query index), the compaction and rebuild worker wired to the bus.

**What does not go here:** Database scanners for PostgreSQL, SQLite, MySQL, Redis, MinIO, Elasticsearch, pgvector (java2 handlers).

**Rule:** edit only the folders you own. If you need a change in someone else folder, message the owner or open an issue.
