# ml/early-ml/embeddings

**Who works here:** ml1 (three real apps, canaries, vector and index scanning, early ML items in weeks 1-12); reviewer ml2 (Tier-1 and Tier-2 model, retrained twin, four forgetting checks, calibration)

**What goes here:** Code that computes the frozen sentence embeddings once. The output files go to shared/ml1/ and are never recomputed by others.

**What does not go here:** The embedding files themselves.

**Rule:** edit only the folders you own. If you need a change in someone else folder, message the owner or open an issue.
