# ml

**Who works here:** ml1, ml2 and ml3, each in their own folder.

**What goes here:** Python code, one environment per folder (own pyproject.toml, lock file, virtual environment).

**What does not go here:** Java code, datasets, weights or embeddings (shared/).

**Rule:** edit only the folders you own. If you need a change in someone else folder, message the owner or open an issue.
