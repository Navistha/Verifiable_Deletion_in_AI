# registry

**Who works here:** Each id in its own sub-folder.

**What goes here:** One small YAML per model, dataset or embedding version: name, version, date, sha256, where it lives in shared/, config used. Weights themselves stay out of git.

**What does not go here:** Weights, embeddings or dumps.

**Rule:** edit only the folders you own. If you need a change in someone else folder, message the owner or open an issue.
