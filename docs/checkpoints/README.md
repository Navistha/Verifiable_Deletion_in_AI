# docs/checkpoints

**Who works here:** Everyone writes their own note; java1 writes each month summary.md.

**What goes here:** One folder per checkpoint (month-01 to month-09, and final for week 40), each with one note per id and summary.md. Each note says what is done and where the proof is, what is late, what is blocked, and one risk.

**What does not go here:** Progress lists (docs/<id>/progress.md).

**Rule:** edit only the folders you own. If you need a change in someone else folder, message the owner or open an issue.
