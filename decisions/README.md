# decisions

**Who works here:** Everyone.

**What goes here:** Short decision records and failed attempts, one file per record, named date-id-slug.md (for example 2026-11-14-ml2-membership-check-failed.md). Draft contract ideas also go here.

**What does not go here:** Results tables (experiments/) or run notes.

**Rule:** edit only the folders you own. If you need a change in someone else folder, message the owner or open an issue.
